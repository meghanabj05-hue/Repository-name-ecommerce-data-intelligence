# E-Commerce Data Intelligence Platform

An end-to-end data project built using the Olist Brazilian E-Commerce dataset.

## Project Goals

- Understand and clean raw e-commerce data
- Build a data processing pipeline
- Store and analyze data using SQL
- Create business analytics dashboards
- Perform customer segmentation
- Build sales forecasting models

## Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Scikit-learn
- Git & GitHub
